Dataset y Variable Objetivo#

En esta sección se presenta el conjunto de datos utilizado en el proyecto y se define la variable objetivo del problema de clasificación.

El dataset corresponde a Lending Club Loan Data (2007–2020), obtenido desde Kaggle. Este conjunto de datos contiene información de préstamos otorgados, incluyendo variables socioeconómicas, financieras, de crédito, empleo y propósito del préstamo.

Siguiendo la condición del proyecto, se trabajará con el dataset completo, sin realizar ningún tipo de muestreo, submuestreo o reducción arbitraria de filas.

El objetivo del proyecto es construir un modelo de clasificación supervisada que permita predecir si un préstamo termina en incumplimiento (default) o si es pagado completamente (fully paid).

Para esto primero se revisa la lectura del dataset, ajustando la ruta según sea necesaria:

import pandas as pd
from pathlib import Path

Definición de la variable objetivo#

La variable objetivo del problema se construye a partir de la columna loan_status.

Se define la variable binaria default de la siguiente forma:

  • 0 = Fully Paid

  • 1 = Charged Off

Sin embargo, la columna loan_status contiene también otros estados intermedios como Current, Late (31-120 days) o In Grace Period. Estos estados no representan un desenlace final del préstamo, pero para el proposito de la evaluación de los modelos a usar, se tomarán en cuenta para el valor de Fully paid.

Después de esta categorización, se genera la variable default.

df["default"] = df["loan_status"].apply(lambda x: 1 if x == "Charged Off" else 0)

Podemos ver los resultados de la clasificación de la siguiente forma:

print("Distribución de la variable default:")
